# Giới Thiệu Dự Án (brain4agent v1.1.0)

## 1. Mục tiêu (Goals & Objectives)
- **brain4agent (v1.1.0):** Là Tổng Hành Dinh nghiên cứu, tối ưu hóa và chuẩn hóa hệ thống Bộ Nhớ Đa Tầng (Multi-Tier Hot/Cold Memory Architecture) cho toàn bộ AI Agents trong mọi dự án.
- **Nguồn Cội Skill Toàn Cầu:** Nơi phát triển, bảo trì và phát hành các Universal Skills như `.xay-dung-nao-bo` và `.compact` trong `.agents/skills/` trước khi deploy ra kho Global Config (`C:\Users\hoang\.gemini\config\skills\`).
- **Lưu Giữ Hiến Pháp Quản Trị:** Định nghĩa chuẩn mực bất biến cho toàn bộ hệ sinh thái (Startup Protocol Bước 0, Spec-First Planning Framework, Model Tiering 🔴/🟠/🟢, Mandatory Sync Cascade 6 điểm, Single Skill Vault, Root Clean 100%).

## 2. Công nghệ cốt lõi (Tech Stack)
- **Scripting & Engine:** Node.js (CommonJS, `fs`, `path` native runtime).
- **Automation & Deployment:** PowerShell (`deploy_skills.ps1`).
- **Data & Governance:** Markdown (GFM), JSON Schema (`state.json`), Mermaid Flowcharts.
- **Version Control & CI/CD:** Git Conventional Commits, Semantic Versioning 2.0.0 (`v1.1.0`).
